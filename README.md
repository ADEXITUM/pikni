# Пикни

Система учёта товарно-материальных ценностей для сети алкомаркетов со сканированием штрихкодов, акцизных марок и кодов «Честного знака» камерой обычного смартфона.

Учебный проект к выпускной квалификационной работе «Разработка автоматизированной системы учёта товарно-материальных ценностей с интеграцией сканера штрихкодов и генерацией отчётов» (БГПУ, 2027). Сеть «Чекушка», её точки и данные вымышлены. ЕГАИС и «Честный знак» заменены учебным имитатором `govsim`, все марки и коды в нём ненастоящие.

## Что умеет

- приёмка по ТТН ЕГАИС в четырёх режимах: по документу, по коробам, выборочно, поштучно;
- передача в торговый зал, перемещения между точками, списание боя, ревизия с помарочным сличением;
- учебная касса с проверками продажи алкоголя: время, возраст, марка, «Честный знак», минимальная цена;
- наличие по всей сети и похожие товары, брони, справочная страница для покупателей;
- сверка с ЕГАИС, журнал учёта продаж, отчёты и печатные формы;
- смартфон как сканер, в том числе беспроводной сканер для ПК, и работа без сети.

## Статус

Первая очередь ТЗ готова и проверена (протокол — [docs/test-protocol.md](docs/test-protocol.md)), из второй — формы ТОРГ и XYZ-анализ. План и ход работ — [docs/plan.md](docs/plan.md).

## Запуск для разработки

Нужны Docker Desktop, Go 1.27, Node.js 24 и [Task](https://taskfile.dev).

```bash
task install      # зависимости фронтенда
task dev          # PostgreSQL + API с автоперезапуском + фронтенд: http://localhost:5173
task dev OBS=1    # то же + Grafana с трассировками, метриками и журналами: http://localhost:3000
task seed         # тестовые точки сети
task admin -- create-admin -login admin   # первый администратор, печатает временный пароль
task admin -- reset-password -login admin # новый временный пароль
task gen          # код из OpenAPI и SQL
task check        # линтеры и тесты, как в CI
```

Интеграционные тесты поднимают PostgreSQL в Docker (testcontainers); `go test -short` их пропускает.

## Демо-данные и сценарии

Чтобы проверить систему руками на данных, похожих на настоящую сеть:

```bash
task demo                         # демо-сеть с годом истории: из копии в .demo/, а нет копии — собрать (около часа)
task dev                          # API, имитатор ЕГАИС и фронтенд
task scenario -- list             # готовые состояния: ревизия идёт, ТТН с пересортом, бой ждёт второго ключа…
task scenario -- all              # применить все (или одно: task scenario -- stocktake-counting)
```

Демо-сеть «Чекушка»: реальный ассортимент крупного алкомаркета — 2051 позиция настоящих брендов
(`api/db/seed/catalog-full.csv`, генерирует `pikni-admin gen-catalog`), три крупных магазина, магазин
у дома и два склада; год поставок, перемещений и продаж через кассы. Вход под любой ролью — логины
печатает `task users`, пароль `Пикни-демо-2026`, PIN кассира 2468. Короткие логины первого магазина:
`upr`, `keeper`, `kassir`; руководство — `director`, `buh`, `admin`.

Федеральная сеть на 3000 магазинов для нагрузочных испытаний — в отдельной базе:
`pikni-admin seed-federal`, `seed-load` и `loadtest -plan` (решение 0063).

Все команды — `task --list`.
