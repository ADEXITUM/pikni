# План реализации АС «Пикни»

Разработка идёт вертикальными срезами. Каждая итерация доводит одну функцию через все слои: БД → SQL → сервис → API → экран → тесты → демо. Срок – весна–лето 2027 г., в объёме обеих очередей ТЗ. Предметная область – учебная сеть алкомаркетов.

Ритм итерации:
1. План и решения: варианты с рекомендацией, выбор за пользователем.
2. Маленькие шаги. После каждого шага – объяснение, команда для проверки, ожидание «дальше».
3. Тесты.
4. Демо.
5. Итог: коммит, запись в `docs/decisions/`, вопросы к защите в `docs/defense-qa.md`.

Отложенные задачи:
- событие «сеанс завершён» по WebSocket, чтобы завершённый сеанс сразу выходил на всех вкладках, — с каналом реального времени (итерация 7);
- повторяющиеся дни запрета продажи (например, «каждый год 1 сентября») — сейчас каждый год вносится отдельной датой;
- повторная отправка перемещения, ТТН которого отклонила ЕГАИС: сейчас его марки остаются «в пути», сверка с ЕГАИС это показывает;
- сканы без связи пока копятся только в документах и ревизии; «Сканер» и брони без связи не работают.

Пояснительная записка пишется параллельно:
- глава 1 – во время итераций 0–3;
- глава 2 – по проектным документам и брендбуку;
- глава 3 – после итерации 12.
