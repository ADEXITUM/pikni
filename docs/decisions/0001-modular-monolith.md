# 0001. Модульный монолит, а не микросервисы

**Статус:** принято, 22.10.2026.

**Контекст.** Проведение документа меняет остатки, марки, очередь в ЕГАИС и журнал действий. Всё это должно произойти целиком или не произойти вовсе. Нагрузка — десятки пользователей и касс, сопровождение — один человек, развёртывание — один VPS.

**Решение.** Один сервер на Go, разделённый на модули с правилами:
- модуль владеет своими таблицами;
- другие модули обращаются к ним только через его сервис;
- циклические зависимости запрещены.

Отдельными процессами вынесено только то, что этого требует: обработчик фоновых задач, генерация PDF, имитатор внешних систем.

**Последствия:**
- **плюс:** согласованность одной транзакцией БД, простое развёртывание, отладка в одном процессе;
- **минус:** модули масштабируются вместе, но копий сервера можно запустить несколько (0008);
- границы модулей позволяют выделить модуль в сервис позже.

**Отвергнуто:**
- **микросервисы:** распределённые транзакции, саги и компенсации, десяток контейнеров и сетевых вызовов без выгоды на нашем масштабе.
