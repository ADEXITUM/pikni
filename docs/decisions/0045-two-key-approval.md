# 0045. Списание и сторно — «двумя ключами»: учёт меняется только после утверждения

**Статус:** принято, 24.10.2026.

**Контекст.** Списание, корректировка остатков по ревизии и отмена проведённого документа вступают в силу только после утверждения другим пользователем с правом утверждения (ПБ-8). Для боя нужна фотография (СО-5). Повреждённую марку сканер может не прочитать.

**Решение:**
- **«Отправить на утверждение»** вместо «Провести»: документ получает статус `pending_approval`, движений нет. Списание по причине с отметкой «нужно фото» (бой) без фотографии не отправляется;
- **утверждает другой человек**: право `docs.approve` (руководитель) и не автор и не тот, кто отправил. Решение — запись в `document_approvals` с комментарием и в журнале действий. «Утвердить» проводит документ, «Вернуть на доработку» делает его снова черновиком;
- **утверждённое списание** уменьшает остаток зоны, списывает марки и ставит в очередь ЕГАИС акт списания: со склада — `ActWriteOff` (регистр 1), из торгового зала — `ActWriteOffShop` (регистр 2), продукция с марками — по маркам;
- **недостача перемещения** списывается из «в пути» получателя, а акт уходит от отправителя: по акту расхождения ЕГАИС вернула непринятое на его баланс (решение 0044);
- **фотографии** хранятся в базе (JPEG до 3 МБ): клиент уменьшает снимок до 1600 px, с телефона это сотни килобайт. Повреждённую марку выбирают из списка марок на остатке зоны;
- **сторно** — отдельный документ со ссылкой на исходный, тоже через утверждение. Сторнируются ввод остатков и передача в зал без пива: у остальных документов есть след в ЕГАИС, их исправляет ответный документ (возврат, перемещение, списание). Исходный документ получает статус «сторнирован».

**Последствия:**
- **плюс:** ни один человек не может один списать бутылку — классическая защита от хищений;
- **плюс:** руководитель видит документы на утверждении во всех точках, история решений хранится;
- **минус:** сторно документов с ЕГАИС невозможно — так и в жизни: акт ЕГАИС не «отменяется», а перекрывается встречным документом.

**Отвергнуто:**
- **флаг «утверждён» без отдельного статуса:** документ на утверждении нельзя было бы отличить от черновика и защитить от правок;
- **фото на диске сервера:** понадобились бы резервное копирование и очистка отдельно от базы; при объёме сети база проще.
