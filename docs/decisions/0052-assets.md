# 0052. Учёт имущества: карточка с историей только на добавление, инвентаризация без документа

**Статус:** принято, 24.10.2026.

**Контекст.** Холодильники, витрины, кассовое оборудование и мебель точек — не товар: у них нет остатков и ЕГАИС, зато есть инвентарный номер, материально ответственное лицо (МОЛ) и состояние (ИМ-1). Перемещения и смена МОЛ должны оставлять историю (ИМ-3), списание — утверждаться (ИМ-5).

**Решение:**
- **отдельный модуль** `assets`, не через регистр движений товара: у объекта нет количества, а только «где, у кого, в каком состоянии»;
- **инвентарный номер** INV-000001 выдаёт последовательность базы; его распознаёт сканер (решение 0025), наклейка несёт Code 128 и QR-код с тем же номером (ИМ-2);
- **история** — таблица `asset_events` только на добавление: принят к учёту, перемещён, сменился МОЛ, сменилось состояние, оформлено, отклонено или утверждено списание. Одно действие «переместить» пишет отдельные строки на точку и на МОЛ;
- **списание «двумя ключами»** — заявка (`asset_writeoffs`) от бухгалтера, решение руководителя с правом утверждения, не того же человека. Утверждённое списание даёт акт в PDF;
- **инвентаризация** — сканы наклеек в точке без документа учёта: результат по каждому объекту считается запросом (найден, не найден, найден здесь, но числится в другой точке). При завершении найденное из других точек можно перевести сюда с записью в истории;
- **права:** вести карточки и инвентаризацию — `assets.edit` (бухгалтер), смотреть — `assets.view` по своим точкам, утверждать списание — `docs.approve`.

**Последствия:**
- **плюс:** история объекта восстанавливается полностью — кто, когда и почему перевёл холодильник;
- **минус:** амортизация не считается — это задача бухгалтерской программы; система хранит первоначальную стоимость.

**Отвергнуто:**
- **имущество как товар в регистре:** пришлось бы вводить количества и зоны там, где их нет;
- **инвентаризация имущества документом с утверждением:** результат ничего не списывает и не приходует сам — расхождения разбирают перемещением или списанием, у которых есть свои подтверждения.
