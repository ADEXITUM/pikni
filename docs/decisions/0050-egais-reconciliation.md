# 0050. Сверка с ЕГАИС: ежедневный запрос остатков и отчёт только о расхождениях

**Статус:** принято, 24.10.2026.

**Контекст.** Учёт точки и её баланс в ЕГАИС расходятся: не дошёл акт, отклонили ТТН, продали бутылку без марки в чеке (СО-9). Найти это нужно раньше проверяющего.

**Решение:**
- **запрос остатков** `QueryRests` ставится в общую очередь обмена с УТМ раз в сутки по каждой точке с ФСРАР ИД и по кнопке. Ответ сохраняется снимком (`egais_rests_snapshots`);
- **сравнение** — со снимком, а не с запросом в реальном времени: продукция без марок по регистрам (1 — склад и склад магазина, 2 — торговый зал), марки поштучно со статусами «на остатке» и «отложена»;
- **отчёт** показывает только расхождения, с подсказкой, что проверить. У марки, которой нет на остатке точки, — что о ней знает система: например, «в пути» по перемещению со ссылкой на документ.

**Последствия:**
- **плюс:** на стенде сверка сразу нашла марки отклонённого ЕГАИС перемещения, которые числятся у отправителя;
- **минус:** снимок отстаёт от учёта на время ответа УТМ — движения за эту минуту дадут ложное расхождение, его снимает повторный запрос.

**Отвергнуто:**
- **автоматическое исправление учёта по ЕГАИС:** расхождение — повод для разбирательства, а не для тихой правки; исправляют ревизией или актом.
