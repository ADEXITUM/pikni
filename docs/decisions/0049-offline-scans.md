# 0049. Сканы без связи: очередь на устройстве, повторная отправка по идентификатору скана

**Статус:** принято, 24.10.2026.

**Контекст.** В подсобках и на складе связь пропадает (СК-8). Ревизию и приёмку нельзя останавливать из-за Wi-Fi.

**Решение:**
- **скан, который не дошёл до сервера** (нет сети, сервер недоступен), сохраняется в localStorage устройства вместе с документом и зоной. Экран показывает, сколько сканов ждёт отправки, работа продолжается;
- **отправка** — когда браузер сообщает о появлении сети и каждые 15 секунд, по порядку сканирования. Идентификатор скана создан на устройстве, поэтому повтор после обрыва посреди ответа сервер не засчитает дважды;
- **отказ сервера** (например, зону уже закрыли) не блокирует очередь: скан уходит из очереди в список «не засчитаны» с причиной.

**Последствия:**
- **плюс:** сотрудник не теряет сканы и не ждёт сеть;
- **минус:** пока связи нет, экран не показывает, что найдено по скану, — исход виден после отправки;
- **минус:** очередь живёт в одном браузере: если сменить устройство до отправки, сканы останутся на старом.

**Отвергнуто:**
- **сервис-воркер с Background Sync:** не поддерживается в Safari на iPhone;
- **IndexedDB:** для десятков небольших записей localStorage проще и надёжнее.
