# 0044. Перемещение между точками: поступление заводится при отгрузке, ТТН к нему привязывается

**Статус:** принято, 24.10.2026.

**Контекст.** Точка заказывает товар из другой точки (СО-4, НЛ-3). Отправитель согласует, собирает по сканам и отгружает с ТТН в ЕГАИС; товар «в пути»; получатель принимает сканированием, расхождения — актом. В перемещении бывает и товар без алкоголя, на который ТТН ЕГАИС не нужна.

**Решение:**
- **документ «Перемещение» ведёт отправитель**: `location_id` — откуда, `dest_location_id` — куда; виден в обеих точках. Статусы: `requested` → `draft` (сборка) или `rejected` → `in_transit` → `posted`. Заявку подаёт получатель (право `transfer.request`), согласует и отгружает отправитель (`transfer.edit`);
- **отгрузка** списывает собранное со склада отправителя по средней и ставит его «в пути» на склад получателя — отдельная корзина регистра `in_transit`, запас организации не меняется. Марки уходят «в путь». На алкоголь в ЕГАИС уходит ТТН;
- **поступление у получателя создаётся при отгрузке** из самого перемещения: план — отгруженное, ожидаемые марки — отгруженные, приёмка поштучно. Когда ТТН дойдёт из ЕГАИС, она привязывается к этому поступлению по идентификатору, который УТМ вернул отправителю. Так товар без алкоголя не теряется, а приёмка повторяет обычную (решение 0038);
- **проведение приёмки** переводит принятое из «в пути» в остаток, принятые марки — в зону получателя; акт по ТТН уходит в ЕГАИС. Непринятое остаётся «в пути» до акта списания с утверждением (итерация 8). Квитанция на акт проводит и перемещение;
- **в имитаторе** точка может отправить ТТН другой точке: марки и регистр отправителя проверяются, отказ на любой позиции откатывает весь документ (точка сохранения).

**Последствия:**
- **плюс:** «в пути» видно в карточке наличия, и это честный учёт: товар принадлежит сети, но его нет ни на одной полке;
- **плюс:** прогон на стенде проходит весь путь: заявка из карточки → согласование (у получателя статус меняется сам) → сборка → ТТН в имитатор → приёмка одной бутылки из двух → акт → оба документа проведены;
- **минус:** отклонённую ЕГАИС ТТН пока нельзя отправить повторно из интерфейса — документ показывает причину, исправление — вручную.

**Отвергнуто:**
- **создавать поступление по пришедшей ТТН, как от поставщика:** товар без алкоголя в ТТН не попадает и потерялся бы;
- **два документа (расход у отправителя и приход у получателя) без связи:** не видно, что товар в пути, и нельзя сверить отгруженное с принятым.
