# 0002. Сервер на Go и Echo v5

**Статус:** принято, 22.10.2026. Echo v4 заменён на v5 в тот же день.

**Контекст.** Серверу нужны много одновременных соединений (кассы, сканы, WebSocket), малое потребление памяти на VPS и простое развёртывание.

**Решение.** Go и веб-фреймворк Echo:
- **Go:** сервер — один исполняемый файл без зависимостей, Docker-образ — десятки мегабайт, горутины дёшевы для тысяч соединений;
- **Echo:** маршрутизация, группы, обработчики ошибок и готовые middleware;
- **версия v5:** во время итерации 0 выяснилось, что интеграция OpenTelemetry для Echo v4 (otelecho) объявлена устаревшей, а официальная `echo-opentelemetry` работает только с v5. Генератор oapi-codegen поддерживает v5 (`echo5-server`). Переход сделан, пока кода мало.

**Последствия:**
- `*echo.Context` — указатель на структуру;
- запуск и корректная остановка сервера делаются одним `StartConfig.Start(ctx, …)`, без ручных горутин;
- журнал Echo — стандартный `log/slog`.

**Отвергнуто:**
- **chi:** меньше готового, чем у Echo;
- **оставаться на Echo v4:** зависимость от устаревшей интеграции.
