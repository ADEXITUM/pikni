# 0046. Брони: резерв в остатках, подтверждение сканом бутылки, выдача только через кассу

**Статус:** принято, 24.10.2026.

**Контекст.** Покупатель по телефону или лично просит отложить товар (НЛ-4). Бронь до конца следующего дня, выдаётся через кассу с обычными проверками продажи; онлайн-оплаты нет — дистанционная продажа алкоголя запрещена. Персональные данные обезличиваются через 30 дней после закрытия (НЛ-5).

**Решение:**
- **бронь оформляет сотрудник магазина** с согласия покупателя на обработку персональных данных (без отметки не сохраняется). Срок считается по местному времени точки — конец следующего дня;
- **подтверждение сканом**: у продукции с марками — марка каждой отложенной бутылки, марка получает статус «отложена»; у остальной — штрихкод товара, количество берётся из брони. Подтверждённая бронь увеличивает `reserved` в остатке зоны (сначала торговый зал), а ограничение `reserved <= on_hand` в базе не даст отложить больше, чем есть;
- **отложенное не продаётся случайно**: касса отказывает по отложенной марке и подсказывает «выдайте через «Брони»»;
- **выдача** — обычный чек со ссылкой на бронь: в одной транзакции снимается резерв, марки возвращаются на остаток, проходят все проверки продажи (время, возраст, ЕГАИС), бронь отмечается выданной с номером чека;
- **фоновая задача раз в минуту** снимает просроченные брони (резерв освобождается) и обезличивает данные броней, закрытых больше 30 дней назад.

**Последствия:**
- **плюс:** в карточке наличия видно «в резерве»; продавец другой смены не продаст отложенную бутылку;
- **минус:** у товара без марок выдаётся любая единица этого товара — так и задумано: штрихкод не различает бутылки.

**Отвергнуто:**
- **бронь без резерва в остатках:** товар продали бы до прихода покупателя;
- **выдача брони списанием в приложении сотрудников:** продажа алкоголя возможна только через кассу с проверками и чеком в ЕГАИС.
