# Протокол испытаний АС «Пикни»

Испытания по разделу 7 ТЗ. Стенд — локальный: PostgreSQL 18 в Docker, два экземпляра API, имитатор
ЕГАИС и ГИС МТ, веб-приложения в Chromium (Playwright). Сервер и домен не арендованы, поэтому
приёмка на публичном стенде не проводилась (раздел «Не проверено»). Дата: 24.10.2026.

Обозначения: **да** — сценарий выполнен; **частично** — выполнена часть, остаток указан;
**нет** — не выполнен.

## 7.1 Виды испытаний

| Вид | Результат |
|---|---|
| Модульные тесты | Go — разбор кодов, правила продажи, расчёты; веб — 114 тестов Vitest (сканер, очередь без связи, сопряжение, сессия) |
| Интеграционные тесты сервера | 22 пакета на настоящем PostgreSQL (testcontainers), в том числе обмен с имитатором; проходят в CI |
| Сквозные тесты интерфейса | Playwright со сканированием камерой (подставное видео со штрихкодом); проходят в CI |
| Нагрузочное испытание | `api/cmd/loadtest`, 100 виртуальных пользователей и касс — см. П-33 |
| Проверка безопасности | govulncheck — 0 уязвимостей в вызываемом коде; npm audit — 2 средние в инструментах тестирования (vitest), высоких и критических нет; права доступа — автотесты П-02 |
| Приёмочные испытания | прогоны итераций на локальном стенде (скрипты walk6–walk12 и снимки экранов) |

## Не проверено

- Работа на арендованном сервере с доменом и сертификатом Let's Encrypt: сборка образов и запуск всего
  стека проверены локально, HTTPS — с самоподписанным сертификатом Caddy.
- Оповещения в Telegram или на почту: канал создаётся в Grafana после развёртывания.
- Lighthouse для основных экранов.
