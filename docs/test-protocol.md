# Протокол испытаний АС «Пикни»

Испытания по разделу 7 ТЗ. Стенд — локальный: PostgreSQL 18 в Docker, два экземпляра API, имитатор
ЕГАИС и ГИС МТ, веб-приложения в Chromium (Playwright). Сервер и домен не арендованы, поэтому
приёмка на публичном стенде не проводилась (раздел «Не проверено»). Дата: 24.10.2026, дополнено 25.10.2026.

Обозначения: **да** — сценарий выполнен; **частично** — выполнена часть, остаток указан;
**нет** — не выполнен.

## 7.1 Виды испытаний

## Не проверено

- Работа на арендованном сервере с доменом и сертификатом Let's Encrypt: сборка образов и запуск всего
  стека проверены локально, HTTPS — с самоподписанным сертификатом Caddy.
- Доставка оповещений в Telegram или на почту: канал создаётся в Grafana после развёртывания. Само
  срабатывание правила проверено (П-37).
